Things I've built.

Select a project to read how it works.

  • A complete machine learning service rather than a notebook. A five-stage training pipeline (data ingestion, validation, transformation, model training and evaluation) is driven by config files, so changing a parameter never means changing code.

    The model is an ElasticNet regression trained on 1,599 red wine samples with 11 chemical features to predict quality. A Flask app exposes training and prediction, the whole thing is containerised with Docker, and GitHub Actions deploys it through AWS ECR to an EC2 runner.

    • Python
    • ElasticNet
    • Flask
    • Docker
    • GitHub Actions
    • AWS ECR and EC2
    View the code on GitHub

  • Most loan models stop at yes or no. This system answers two questions in order: first, should this application be approved, and second, if so, how much should the loan be worth.

    Splitting the problem lets each model specialise, and keeps the amount estimate from being polluted by applications that were never going to be approved. Next steps are deploying it on GCP and training on a larger dataset.

    • Classification
    • Regression
    • Model evaluation
    • Project presentation

  • An end-to-end monthly forecasting pipeline for an electricals and FMCG style business, at the level of individual SKU, sales office and channel. It uses rolling-origin evaluation, so every model is judged on how it would have performed in the past, not on one lucky split.

    It compares a wide field on a realistic synthetic dataset: simple baselines, ETS, ARIMA, Prophet and Theta, intermittent-demand methods like Croston, SBA and TSB, tree-based models, and LSTM and GRU networks.

    • Time series
    • Prophet
    • XGBoost
    • LSTM and GRU
    • Rolling-origin evaluation

  • A calling agent for DASHR Tech, a material handling equipment dealer. "Ria", an inside-sales persona, makes outbound lead generation calls: she explains what the company does and captures the lead.

    The hard parts are the ones that matter in India: switching between Hindi and English mid-sentence, keeping latency low enough to feel like a conversation, and handling Indian accents. It is built on OpenAI's realtime voice API with Exotel for telephony, and an admin console is being added to the company's Next.js site. In active development.

    • Voice AI
    • OpenAI Realtime
    • Exotel
    • Next.js

  • iOS and Android apps built from the DASHR Tech website using React Native and Expo. One covers the material handling equipment catalogue. The other is CardEx, which scans visiting cards offline in the field and syncs them to a backend that uses Gemini and Apify to turn a card into an enriched lead.

    I build these with Claude Code, with a workflow of written specs, planning before coding, and quality and security reviews. In active development.

    • React Native
    • Expo
    • Gemini
    • Apify
    • Claude Code

  • A product design project: a mobile app that lets conductors on Indian public buses issue tickets quickly while the bus is moving and crowded. The deliverable is a Figma design with a clickable prototype.

    It shows how I think about users first, which is a useful habit for anyone who builds models that other people have to rely on.

    • Figma
    • Prototyping
    • User flows
